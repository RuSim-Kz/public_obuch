Задание 1.2. Определение сущностей и атрибутов
Портал «Корочки.есть»

================================================================================
Сущность «Пользователи» (users)
================================================================================
Атрибут      | Описание                          | Тип данных   | Ограничения
-------------|-----------------------------------|--------------|------------------------------------------
id           | Уникальный идентификатор          | целое число  | первичный ключ, автоинкремент
login        | Логин для входа                   | строка       | уникальный, только латиница и цифры,
             |                                   |              | не менее 6 символов
password     | Пароль                            | строка       | минимум 8 символов, хранить в хэшированном виде
full_name    | ФИО пользователя                  | строка       | кириллица и пробелы
phone        | Номер телефона                    | строка       | формат: 8(XXX)XXX-XX-XX
email        | Адрес электронной почты           | строка       | формат email
role         | Роль пользователя                 | строка       | 'user' или 'admin'
created_at   | Дата и время регистрации          | дата/время   | значение по умолчанию — текущая дата

================================================================================
Сущность «Способы оплаты» (payment_methods)
================================================================================
Атрибут      | Описание                          | Тип данных   | Ограничения
-------------|-----------------------------------|--------------|------------------------------------------
id           | Уникальный идентификатор          | целое число  | первичный ключ, автоинкремент
name         | Название способа оплаты           | строка       | 'Наличные', 'Перевод по номеру телефона'

================================================================================
Сущность «Заявки» (applications)
================================================================================
Атрибут              | Описание                      | Тип данных   | Ограничения
---------------------|-------------------------------|--------------|------------------------------------------
id                   | Уникальный идентификатор      | целое число  | первичный ключ, автоинкремент
user_id              | Автор заявки                  | целое число  | внешний ключ к users.id
course_name          | Название курса                | строка       | не пустое
desired_start_date   | Желаемая дата начала обучения | дата         | не пустое
payment_method_id    | Способ оплаты                 | целое число  | внешний ключ к payment_methods.id
status               | Статус заявки                 | строка       | 'Новая', 'Идет обучение', 'Обучение завершено'
created_at           | Дата подачи заявки            | дата/время   | значение по умолчанию — текущая дата
review               | Отзыв о качестве обучения     | текст        | может быть пустым

================================================================================
Связи между сущностями
================================================================================
1. users (1) ——< applications (N)   Один пользователь может подать много заявок
2. payment_methods (1) ——< applications (N)   Один способ оплаты может использоваться в многих заявках
